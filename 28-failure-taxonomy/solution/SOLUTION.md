# Solution, Lesson 28

The as-built configuration alone produces 6 failures: transcription_digits 4 and repair_exhaustion 2. Both escape categories disappear, as does nothing else.

That split is the difference between intrinsic failures and fault-sensitivity. The as-built system's own weaknesses are hearing digits wrong and giving up on hard callers; it does not, as shipped, breach consent or store cards. The escapes in the full taxonomy exist only because the suite deliberately breaks the protections, which is fault-sensitivity: a measure of what a single configuration error would cost. A taxonomy that ran only the shipping configuration could not see the escapes at all, and a team that never injects faults learns about them from incidents instead.

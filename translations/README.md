# Translations

The course is written in English. Community translations are welcome.

To contribute one:

1. Open an issue naming the language, so two translators do not duplicate work.
2. Mirror the folder structure under a language folder (for example `ur/00-course-setup/README.md`).
3. Translate the prose. Keep code, fixture files, and file names unchanged: the smoke tests and validators depend on them, and the numbers in the prose must still match what the code prints.
4. Keep the honesty rules intact in translation: no added claims, no removed negative results, no certificate promises, and simulated numbers still labelled simulated.

A translation that cannot keep the numbers reproducible should say so at the top of its README rather than quietly drifting from the code.

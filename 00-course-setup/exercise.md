# Exercise, Lesson 00: A different tone

Change the verification tone in `check_environment.py` from 440 Hz for 1000 ms to 880 Hz for 500 ms, keeping everything else the same. Before you run it, write down how many samples you expect the WAV round trip to report, and why. Then run it and check.

Then answer in one sentence: if the sample count had come back as anything other than your prediction, which of the three failure classes from the README would you suspect first, and what would you check?

# Exercise, Lesson 22: Lower the run threshold

The counter treats a run of at least four digit words as a recoverable digit string. Recount the corpus with the threshold lowered to three, and compare with the threshold-four count.

Then write two sentences: did the lower threshold find anything the stricter one missed in this corpus, and what does that tell you about the value of testing a redactor against a corpus rather than reasoning about it in the abstract?

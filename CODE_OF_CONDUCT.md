# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1, in full. By participating you agree to its standards: be welcoming and respectful, assume good faith, accept constructive criticism gracefully, and focus on what is best for the community of learners this course serves.

Unacceptable behaviour includes harassment, personal or political attacks, publishing others' private information, and any conduct that would be considered inappropriate in a professional setting.

## Enforcement

Report violations to the maintainers via the contact channels on the [TechAura website](https://techaurah.com). Reports are reviewed promptly and kept confidential. Maintainers may remove comments, commits, and contributions that violate this code, and may ban repeat offenders, following the enforcement ladder in the Contributor Covenant.

## Scope

This code applies in all project spaces (issues, pull requests, discussions) and when representing the project in public spaces.

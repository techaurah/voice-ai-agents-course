# Showcase

Built something with the course's patterns: a booking line for your own trade, a latency ledger for a platform you use, a failure taxonomy of your real call set? Open a pull request adding a short entry here: what you built, which lessons it used, and the numbers you measured (success rates, escapes, p50 and p95 latency, cost per successful call) rather than adjectives.

Entries should follow the course's own standard: claims with the code or fixtures that produced them, honest negatives included. A showcase entry reporting that adaptive endpointing did not help your callers is as welcome as one where it did; Lesson 06 exists because that result is information, not embarrassment.

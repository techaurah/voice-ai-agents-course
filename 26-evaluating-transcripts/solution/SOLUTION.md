# Solution, Lesson 26

With the map restricted to the five service words, mean WER after is 0.0702, identical to the before score. Narrowing the map removed the harm and the help alike: on this fixture set the full map's single helped utterance was not a service garble at all, and its two hurt utterances were collateral from the broader entries.

The general rule is that a post-processor is a recogniser too, with its own error rate, and it earns deployment only when its measured net on a frozen set is positive, with the hurt count inspected, not assumed away. "It only fixes obvious mistakes" is a claim about a distribution, and distributions are settled by counting, not by inspecting the examples that inspired the fix.
